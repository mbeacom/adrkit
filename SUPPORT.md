# Support

Thanks for using adrkit. Here is where to go for help.

## Questions and discussion

Use [GitHub Discussions](https://github.com/mbeacom/adrkit/discussions) for
questions, ideas, and general help:

- **Q&A** — how do I do X, why does Y behave this way.
- **Ideas** — propose a feature or a direction before it becomes an issue.
- **Show and tell** — share how you are using adrkit.

Discussions are the best first stop; the answer may help the next person too.

## Documentation

- [Quickstart](https://adrkit.dev/quickstart/) — install and run in a few minutes.
- [Command reference](https://adrkit.dev/commands/) — every command, flag, and exit code.
- [Use in CI](https://adrkit.dev/ci/) and [MCP setup](https://adrkit.dev/mcp/) — the integrations.
- [Decision records](https://adrkit.dev/adr/) — why adrkit is built the way it is.

## Bugs and feature requests

If you have found a bug or want to request a feature, open an
[issue](https://github.com/mbeacom/adrkit/issues/new/choose) using the
appropriate template. For bugs, please include your adrkit version
(`adr --version`), OS, and steps to reproduce.

## Security issues

Do **not** report security vulnerabilities in public issues or discussions. See
[SECURITY.md](./SECURITY.md) for private reporting.

## Contributing

Interested in contributing? See [CONTRIBUTING.md](./CONTRIBUTING.md), including
the "Your first PR" section for a gentle on-ramp.
